Configuration Firebase requise

Cette application partage le stock en temps réel entre tous les postes via Firebase (gratuit). Un seul membre de l'équipe doit faire cette configuration une fois (~5 minutes) :

  1. Aller sur console.firebase.google.com, se connecter avec un compte Google et créer un projet (ex. « chambrelan-stock »).
  2. Realtime Database → Créer une base de données → région Europe → démarrer en mode test.
  3. Authentication → Sign-in method → activer le fournisseur Anonyme.
  4. Realtime Database → Règles, coller puis publier :
    {"rules":{".read":"auth != null",".write":"auth != null"}}
  5. Paramètres du projet (⚙) → Vos applications → icône Web « </> » → enregistrer une application → copier l'objet firebaseConfig.
  6. Ouvrir ce fichier dans un éditeur de texte, repérer CONFIGURATION FIREBASE en haut du script, et remplacer les 7 valeurs par celles copiées. Enregistrer.
  7. Partager ce même fichier (une fois configuré) à toute l'équipe — chacun l'ouvre dans son navigateur.

Une fois configuré, cet écran ne s'affichera plus.
